# Тестовые чеки

Вымышленные документы «Демо-банка» и «Демо-кассы» для проверки оплат. На каждом есть пометка «ОБРАЗЕЦ ДЛЯ ТЕСТИРОВАНИЯ». Даты операций — 24.10.2026: если тестируете позже, пересоздайте файлы с сегодняшней датой (`pip install reportlab pillow`, затем `python generate.py`).

Как пользоваться: войдите как `user` → «Платежи» → «Приложить чек» у нужного платежа (или нажмите «Оплачено» в напоминании Telegram и пришлите файл боту). Суммы подобраны под демо-данные.

| Файл | К какому платежу | Что должно произойти |
|---|---|---|
| `01_перевод_399_руб_кинотеатр.pdf` | Онлайн-кинотеатр, 399 ₽ | ✅ подтверждается автоматически (текст PDF: сумма, дата, № документа) |
| `02_СБП_299_руб_хранилище.pdf` | Облачное хранилище, 299 ₽ | ✅ автоматически (перевод по СБП, строка «Итого») |
| `03_кассовый_чек_QR_399_руб.png` | Онлайн-кинотеатр, 399 ₽ | ✅ автоматически (читается QR-код кассового чека ФНС) |
| `04_фото_экрана_банка_399_руб.jpg` | Онлайн-кинотеатр, 399 ₽ | ✅ автоматически (фото под углом, OCR) |
| `05_неверная_сумма_350_руб.pdf` | Онлайн-кинотеатр, 399 ₽ | 🔎 администратору: «Сумма не совпадает — 350 ₽ вместо 399 ₽» |
| `06_операция_отклонена_399_руб.pdf` | Онлайн-кинотеатр, 399 ₽ | 🔎 администратору: «Операция не выполнена» |
| `07_чек_возврата_QR_399_руб.png` | Онлайн-кинотеатр, 399 ₽ | 🔎 администратору: QR-код — чек возврата |
| `08_оплата_VPS_15_USD.pdf` | VPS-сервер, 15 $ | ✅ автоматически (англоязычная квитанция в долларах) |
| `09_старый_чек_399_руб.pdf` | Онлайн-кинотеатр, 399 ₽ | 🔎 администратору: «Чек слишком старый» (за 75 дней до операции) |
| `10_аренда_85000_руб.pdf` | Аренда офиса, 85 000 ₽ (общий платёж) | ✅ автоматически (платёжное поручение) |
| `11_не_чек.jpg` | любой | 🔎 администратору: «Не похоже на чек», сумма и дата не найдены |

**Повторное использование:** после того как `01_…pdf` принят для кинотеатра, приложите его к любому другому платежу — будет «Чек уже использован». Дубль ловится и по самому файлу (SHA-256), и по номеру операции или фискальным данным QR-кода, даже если файл пересохранили.

Подходящий чек к платежу с другой суммой (например, `01` к VPS) тоже уйдёт администратору: «Сумма не совпадает», «Другая валюта».

Настоящие PDF-чеки Сбера, Т-Банка, Альфы разбираются тем же способом, что образцы 01, 02 и 05: по строкам «Сумма перевода» / «Итого», дате операции и номеру документа (тесты `internal/receipt/parse_test.go` содержат тексты в формате этих банков). На настоящих файлах банков разбор не проверялся — проверьте своим чеком. Если формат окажется непривычным, чек не потеряется: он уйдёт администратору с пометкой «Сумма не найдена», а в окне проверки будет виден распознанный текст.
